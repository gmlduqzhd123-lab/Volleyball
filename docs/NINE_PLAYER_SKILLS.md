# 배구 기술 교실 · 9인제 검토

검사일: 2026-10-12. 기존 여섯 기술의 준비 자세·동작·연습법에 6인제 전용 자리 로테이션/리베로/후위 공격 제한 안내가 들어 있지는 않았습니다. 공통 기본기는 유지하고 9인제 경기 활용과 규칙을 별도 안내했습니다.

## 확인 자료

대한배구협회 경기규칙 페이지에서 제공하는 9인제 경기규칙 PDF를 사용했습니다.

- https://www.kva.or.kr/user/template.do?fileNm=vlb2_1
- https://www.kva.or.kr/download/9인제배구경기규칙.pdf
- 178–180쪽: 기본 팀 터치, 첫 타구의 연속 접촉 예외, 네트 플레이, 네트 접촉/방해.
- 181쪽: 서비스 순서·시간·타구/도약 시 발 위치, 손에서 놓거나 던진 공의 서브 타구.
- 182쪽: 공격 제한, 네트 상단보다 완전히 높은 상대 서브의 공격 완료 금지.
- 183쪽: 블로킹은 팀 타구에 미포함, 블로커도 다음 접촉 가능, 상대 공격 전에 공 접촉/방해 금지, 상대 서브 블로킹 금지.

규정 PDF의 발행연도는 확인되지 않았습니다. 실제 참가 대회의 경기요강이 우선입니다. 역할·수비 구역은 전술 예시이며 의무적인 배치를 뜻하지 않습니다.

## 변경

- 목록 안내를 9인제 기준으로 표시하고, 여섯 상세 페이지에 기술별 9인제 안내 추가.
- 서브 동작에서 공을 손에서 놓거나 던진 뒤 치는 설명과 흔한 실수를 명확하게 수정.
- `skills.json`에 선택 항목 `ninePlayerNotes` 추가. 기존 구조와 기술별 영상 ID는 유지.
- 참고 영상에는 6인제 촬영 영상도 포함될 수 있음을 안내하며, 영상 제목/설명/출처를 9인제 영상인 것처럼 바꾸지 않음.
- 기존 영상 84개와 기술별 연결 54개(10/10/10/10/6/8)는 유지.

## 검사

빌드와 단위 테스트, PC 1440px·모바일 390/360px에서 여섯 상세 페이지의 안내/연결/가로 넘침/자동 iframe 없음, 서브 동작과 스파이크·블로킹·디그 핵심 문구를 검사했습니다. 공개 사이트에서도 같은 경로를 확인합니다. 실제 휴대전화와 기존 영상의 재생 재검사는 이번 범위에 포함하지 않았습니다.
