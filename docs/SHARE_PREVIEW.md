# 공유 미리보기 2안 적용

2026-10-12: 사용자가 선택한 코트 & 에너지 2안을 적용했습니다. 초록·주황 배경, 배구공과 코트 선, ‘배구, 오늘부터 우리 함께!’ 문구를 사용합니다.

- 대표 이미지: `public/social/volleyball-share-v2.png` (1200×630 PNG).
- 제목: 우리 모두 배구왕 | 배구, 오늘부터 우리 함께!
- 설명: 재미있는 영상과 쉬운 배구 수업을 한곳에서 만나세요.
- 공유 주소: https://gmlduqzhd123-lab.github.io/Volleyball/
- 이미지 공개 주소: https://gmlduqzhd123-lab.github.io/Volleyball/social/volleyball-share-v2.png

index.html에 OG와 Twitter 메타 정보를 정적으로 넣었습니다. 크롤러가 JavaScript 실행 없이 읽을 수 있습니다. 기기 공유 기능의 문구도 선택한 안과 맞췄습니다. QR코드와 링크 복사의 주소는 그대로 유지합니다. 영상 데이터와 메뉴는 변경하지 않았습니다.

검증: 프로덕션 빌드·단위 검사 29개 통과. Chromium에서 실제 링크 복사 검사와 시뮬레이션 공유 API의 제목·문구·URL 검사 통과. 배포 빌드 HTML을 JavaScript 없이 읽고 OG 제목·URL·이미지 주소와 이미지의 PNG 형식·크기를 검사했습니다. 카카오톡 채팅 전송과 실물 기기의 카드 표시는 미검증이며 디자인 시안의 채팅 배경·카드 외곽은 카카오톡 자체 UI에 따라 달라집니다.

카카오톡은 페이지의 OG 정보를 읽어 미리보기를 만들며, 기존 미리보기가 남으면 캐시 초기화가 필요할 수 있습니다. [카카오 공식 문서](https://developers.kakao.com/docs/ko/tool/common)의 ‘카카오톡 URL 메타정보 관리’에서 공개 주소를 조회·초기화할 수 있습니다. 이미 전송한 메시지의 미리보기가 자동으로 바뀐다고 보장하지 않습니다.
