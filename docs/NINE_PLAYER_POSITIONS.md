# 9인제 포지션 교실 변경

검사일: 2026-10-12. 포지션 배우기 페이지와 해당 페이지로 연결되는 홈/입문 교실 안내 문구를 변경했습니다.

## 자료와 해석

- 대한배구협회 경기규칙: https://www.kva.or.kr/user/template.do?fileNm=vlb2_1
- 해당 페이지의 ‘9인제 배구 경기규칙’ PDF: https://www.kva.or.kr/download/9인제배구경기규칙.pdf
- PDF 인쇄 페이지 170–171: 코트 규격과 코트 라인. 3m 공격선을 표시하지 않습니다.
- 173쪽 규칙 4.3.1, 4.3.5: 팀 유니폼은 동일하며 다른 색 유니폼은 금지됩니다. 리베로 제도를 적용하지 않습니다.
- 177쪽 규칙 7, 181쪽 규칙 12.2: 6인제의 위치 로테이션 안내가 없으며 서비스 순서 용지의 타순을 따릅니다. 서빙 팀의 득점은 같은 서버, 리시빙 팀의 득점은 다음 타순 서버입니다.
- 협회가 현재 제공하는 자료의 발행연도는 확인되지 않았습니다. 실제 참가 대회의 경기요강이 우선입니다.

3×3 배치와 선수 1~9, 세터/레프트/라이트/센터/수비 담당은 입문 설명용 예시입니다. 규정상 의무적인 자리, 명칭, 세터 수를 뜻하지 않습니다. 서브 타순 버튼은 서브권을 새로 얻는 상황을 가정하며 자리 배치를 바꾸지 않습니다. 서버는 실제 서브 시 서비스 지역으로 이동합니다.

## 데이터 범위

`positions.json`은 9인제 입문 역할로 변경했습니다. 영상 데이터의 기존 6인제 전문 역할 태그와 기술별 연결은 그대로 유지했습니다. 후속 요청으로 영상 필터 표시는 9인제 학습 역할로 연결했습니다(`NINE_PLAYER_VIDEO_FILTER.md`). 입문 규칙·용어·퀴즈도 9인제로 전환했습니다(`NINE_PLAYER_BEGINNER.md`).

## 검증

- TypeScript/배포 빌드 및 기존 단위 테스트.
- 브라우저 테스트: 아홉 선수 선택, 키보드 선택, 서브 타순 1→9→1, 초기화, 타순 변경 중 자리 유지, 수비 담당 설명.
- PC 및 모바일 뷰포트: 메뉴 이동, 화면 넘침, GitHub Pages 하위 경로 직접 접속/새로고침.
- 공개 배포 페이지의 변경 데이터 및 화면 확인. 실제 휴대전화 검사는 별도로 수행하지 않았습니다.
