# 메뉴 이름과 영상관 통합

2026-10-12 수정: 상단과 모바일 메뉴 순서는 홈 → 배구 영상 → 왕초보 배구 교실 → 배구 기술 교실 → 포지션 배우기입니다. 메뉴, 페이지 제목, 브라우저 제목과 홈의 연결 문구를 함께 수정했습니다.

프로배구 영상관 메뉴를 제거하고 배구 영상의 프로팀 경기 탭을 사용합니다. 기존 `#/pro` 링크는 배구 영상 화면에서 프로팀 경기를 선택한 상태로 열립니다. 그 화면에서도 다른 카테고리로 바꿀 수 있습니다. 모바일에서 현재 페이지 메뉴를 다시 누를 때에도 메뉴를 닫도록 보완했습니다.

영상 JSON 84편과 기술별 연결은 변경하지 않았습니다. 저작권·QR·공유·PWA 기능도 유지합니다.

검증: TypeScript·프로덕션 빌드, 단위 검사 29개, 관련 Chromium 브라우저 검사 5개 통과. 1440px PC, 390px·360px 모바일 뷰포트에서 다섯 메뉴의 순서·클릭 이동·브라우저 제목·선택 표시와 가로 넘침을 확인했습니다. 프로팀 경기 10편, 기초 영상 54편, 예능배구 10편, 초등 배구 10편과 기술별 연결 검사도 통과했습니다. 모바일 검사는 브라우저 뷰포트 검사이며 실물 휴대폰 검사가 아닙니다.
