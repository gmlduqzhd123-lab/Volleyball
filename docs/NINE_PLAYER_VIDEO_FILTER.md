# 배구 영상 · 9인제 포지션 필터

포지션 배우기의 입문 역할과 영상 필터/카드/상세/관리자 입력의 역할 표시를 세터·레프트·라이트·센터·수비 담당으로 맞췄습니다.

| 기존 원본 태그 | 9인제 학습 필터 |
|---|---|
| setter | 세터 (setter) |
| outside | 레프트 (left) |
| opposite | 라이트 (right) |
| middle | 센터 (center) |
| libero | 수비 담당 (defense) |

이는 관련 학습 역할을 찾기 위한 분류입니다. 6인제의 리베로 제도를 9인제에 적용하거나 원본 영상의 선수 역할/경기 형식을 바꾸는 것이 아닙니다. 화면에 해당 범위를 안내합니다. 원본 유튜브 제목·설명도 바꾸지 않았습니다.

기존 `videos.json`의 84개 영상과 모든 `positionTags`를 보존하고, 필터 시점에 대응 역할을 구합니다. 새로운 9인제 역할 태그와 기존 태그를 모두 검증/검색할 수 있으며 관리자 도구는 새 역할 태그를 생성합니다. 혼합 태그는 화면에서 중복 표시하지 않습니다. 영상 카테고리·검색·최신 날짜순·클릭 후 플레이어 로딩·기술별 videoIds는 유지합니다.

검사: 새/기존 태그 호환성과 원본 보존 단위 테스트, PC 1440px·모바일 390/360px의 다섯 필터·카테고리/검색 결합·상세·화면 넘침·자동 iframe 없음, 기존 기술별 영상 연결 및 관리자 입력 테스트. 공개 배포 후 같은 필터와 목록 수를 재확인합니다. 실제 휴대전화와 기존 영상 전체 재생 재검사는 별도입니다.
