# 왕초보 배구 교실 · 9인제 규칙과 퀴즈

검사일: 2026-10-12. 기존 6인제 규칙 설명을 9인제 기준으로 전환했습니다.

## 확인 자료

대한배구협회 경기규칙 페이지의 ‘9인제 배구 경기규칙’ PDF를 확인했습니다.

- https://www.kva.or.kr/user/template.do?fileNm=vlb2_1
- https://www.kva.or.kr/download/9인제배구경기규칙.pdf
- 170–171쪽: 종별 코트 규격, 코트 라인, 서비스 지역.
- 173쪽 4.3: 같은 팀 유니폼, 다른 색 유니폼 금지. 리베로 제도 없음.
- 176쪽 6.2–6.3: 21점, 2점 차, 2세트 선승.
- 178–180쪽 9.1, 9.2, 10.3: 기본 3회 팀 터치, 블로킹 제외, 첫 터치의 연속 접촉 예외, 네트에 맞은 공의 한 번 재접촉(4번째 팀 터치 가능).
- 180쪽 11.3: 인플레이 중 신체/유니폼 네트 접촉 반칙, 볼이 네트를 밀어 상대에게 접촉하는 예외.
- 181쪽 12.2–12.4: 타순, 서버 유지/다음 서버, 서비스 허가 후 8초, 타구/점프 도약 시 발 위치.

협회 제공 PDF의 발행연도는 확인되지 않았습니다. 참가 대회의 경기요강이 기본 안내보다 우선하며, 점수·세트·코트 규격 등 대회별 차이가 있을 수 있음을 화면에 표시했습니다.

## 변경

- 규칙 8개: 점수, 코트/인원, 기본 터치, 네트 플레이, 서브, 서브 타순, 수비 담당, 네트 접촉.
- 용어의 로테이션/리베로 항목을 서브 타순/수비 담당으로 전환.
- 퀴즈 10문항의 질문·보기·정답·해설을 9인제 기준으로 정비.
- 기존 6인제 퀴즈 기록은 삭제하지 않으며 9인제의 지난 기록으로 표시하지 않음. 새 결과는 `nine-player-v1` 규정 표식으로 구분.
- 교실/퀴즈 안내와 공식 규정 링크를 일치시킴. 영상 데이터·기술별 영상 연결·QR/공유/설치 기능은 유지.

## 검사

단위 테스트, 빌드, PC 1440px 및 모바일 390/360px 브라우저 화면과 검색/규칙 전환, 퀴즈 정답·해설·10점 결과·새로고침·이전 기록 구분을 검사했습니다. 기존 오답 및 재도전 검사도 실행했습니다. 공개 사이트에서도 동일 항목을 확인합니다. 실제 휴대전화 검사는 별도입니다.
