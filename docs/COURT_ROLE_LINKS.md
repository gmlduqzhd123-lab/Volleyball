# 코트 번호와 역할 설명 연결

검사일: 2026-10-13, Asia/Seoul.

## 변경 내용

번호와 역할이 각각 별도의 상태로 관리되어 번호 선택 후 오른쪽 역할 설명이 바뀌지 않았다. 선수 번호 하나로 연결 역할을 계산하도록 변경했다. 번호의 강조 표시, 역할 버튼의 강조 표시, 위치·역할·초보자 팁이 함께 갱신된다.

역할 버튼을 누르면 해당 역할의 대표 예시 위치를 선택한다. 이미 같은 역할의 번호를 선택했다면 현재 위치를 유지한다. 서브 타순은 별도의 상태로 유지하고 번호/역할 선택과 혼동하지 않는다.

모바일에서는 코트 바로 아래에서도 선택 위치, 역할과 팁을 확인할 수 있다. ‘선수 N 역할 설명 보기’ 버튼은 상세 설명으로 이동하고 초점을 제공한다. 동작 감소 설정을 존중한다. 번호는 마우스·터치·Enter·Space로 조작할 수 있다.

## 학습용 역할 연결표

왼쪽·오른쪽은 우리 코트에서 네트를 바라보는 기준이다.

| 설명용 번호 | 위치 예시 | 연결 역할 |
|---|---|---|
| 1 | 전위 왼쪽 | 레프트 |
| 2 | 전위 중앙 | 센터 |
| 3 | 전위 오른쪽 | 라이트 |
| 4 | 중위 왼쪽 | 수비 담당 |
| 5 | 중위 중앙 | 세터 |
| 6 | 중위 오른쪽 | 수비 담당 |
| 7 | 후위 왼쪽 | 수비 담당 |
| 8 | 후위 중앙 | 수비 담당 |
| 9 | 후위 오른쪽 | 수비 담당 |

이 연결은 학습용 배치 예시다. 규정상 의무 배치, 공식 포지션 번호 또는 서브 타순이 아니다. 팀의 전술에 따라 세터 수와 공격·수비 분담 및 위치는 달라진다.

## 참고 자료와 적용 범위

- 사용자 지정 자료: [한국9인제배구연맹의 9인제 규칙](https://k9vf.or.kr/pages/volleyball/rules.html). 2026-10-13 HTTP 200으로 확인했다. 전위·중위·후위 배치 설명을 학습에 참고했다. 가운데 세터 배치와 오른쪽 후위 서브 설명을 모든 팀의 의무 규정으로 해석하지 않는다.
- 기존 앱의 규정 출처: [대한배구협회 경기규칙](https://www.kva.or.kr/user/template.do?fileNm=vlb2_1)의 [9인제 경기규칙 PDF](https://www.kva.or.kr/download/9인제배구경기규칙.pdf). 당일 다시 다운로드한 PDF가 기존 검토 파일과 SHA-256으로 일치함을 확인했다.
- 규정 차이: 연맹 웹 페이지는 25점제, 협회 PDF 인쇄 176쪽의 6.2는 21점제로 안내한다. 협회 PDF 181쪽 12.2는 서비스 순서 용지를 기준으로 한다. 출처별 기준을 혼합해 모든 대회에 적용되는 규칙으로 단정하지 않는다.
- 이 변경에서는 기존 앱의 협회 기준 규칙·퀴즈를 유지하고 포지션 화면에 자료 차이를 안내한다. 실제 대회에서는 해당 경기요강을 먼저 확인해야 한다. 협회 PDF의 발행연도와 연맹 페이지의 적용 대회 범위는 확인되지 않았다.

기존 영상 JSON, 기술별 영상 연결, 역할 데이터 JSON, 저작권·QR·공유·PWA 기능은 유지했다.

- TypeScript와 Vite 배포 빌드.
- 단위 검사 30개와 브라우저 검사 29개.
