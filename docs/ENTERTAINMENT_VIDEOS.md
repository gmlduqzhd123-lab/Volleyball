## 재생 검사

환경: Windows 데스크톱 Chrome, 한국어 YouTube 플레이어, 검사일 2026-10-12. 로컬 주소 http://127.0.0.1:5173/ 의 실제 상세 화면에서 플레이어 열기를 누른 뒤 임베드 안의 동영상 재생 버튼을 눌렀습니다. 광고 표시가 없는 본 영상이 일시정지되지 않았고 두 관측 사이의 currentTime이 0.5초 이상 증가한 경우만 통과했습니다. 자동재생 파라미터는 사용하지 않습니다. 각 영상의 상태·시간·검사 주소는 [로컬 기록](entertainment-playback-local.json)에 보관합니다.

공개 사이트 재생 검사는 배포 후 진행하여 별도 기록합니다.
